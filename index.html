A SMALL, CLEAR FLOW

Three steps. Nothing extra.

01↗

Write

Type the message you want to share. Text only, with no media permissions.

02⌗

Share the code

QuietSend saves the message in your existing Firebase Realtime Database and gives you a four-digit code.

03✓

Receive once

The recipient enters the code to retrieve the text. The app attempts to remove the record after a successful retrieval.

A note on privacy. Four-digit codes can be guessed and do not encrypt message content. Database rules must enforce who can read, create, and delete messages. Client-side deletion is best-effort, not a guaranteed secure-erasure mechanism.
